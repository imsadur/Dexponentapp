# DBv3 design system

DBv3 is an independent institutional capital workspace. It uses a graphite background, ink surfaces, cool lavender actions, mint positive states, and warm amber warnings. Typography uses Outfit for a compact but legible financial interface.

## Layout

- Fixed 240px desktop navigation with a 68px utility bar.
- Content width up to 1480px with 28–40px page gutters.
- Tables for repeatable financial objects; cards only for summaries, focused workflows, and empty states.
- Mobile navigation becomes a dismissible drawer below 960px.

## Components

- Buttons: 42px minimum height, 10px radius, visible focus outline, one primary action per screen.
- Inputs: 44px minimum height, 10px radius, persistent labels, clear selected and error states.
- Panels: 14px radius, 1px border, no decorative glass effects.
- Status: always includes text; color is supportive and never the only signal.
- Motion: short state transitions and number animation only; reduced-motion preferences disable them.

## Product language

- Farm is the primary product object.
- Portfolio means the liquidity provider's own demo balances.
- Managed Farms means Farms operated by the current manager.
- Every financial number is labeled Demo, Simulated, Estimated, or Actual.
