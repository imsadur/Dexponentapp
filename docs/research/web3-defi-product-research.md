# DeFi product research

Reviewed 7 September 2026, before substantial application code. Sources are official documentation and publicly accessible product pages. These are product-pattern observations and design inferences, not investment recommendations or a live security assessment. Browser-only product shells did not expose authenticated screens; no claim is made to have transacted or completed competitors' flows. Some legacy docs redirected or were unavailable; limitations are recorded below.

## Applied synthesis

Keep overview metrics compact and farm rows rich in status. Put draft recovery beside the main Create Farm CTA. Use strategy → template → configure → review → simulate → deploy, with a consistent live flow across types. All market fixtures are labeled demo. A deterministic scenario model is labeled hypothetical rather than a backtest. Configuration readiness is a separate state from live contract readiness. Use native dialogs, errors, focus and responsive panels; do not copy competitor branding or claim audited strategies.

## Follow-up research before live release

Authenticated desktop/mobile walkthroughs, provider-specific approval flows, current protocol-chain-token compatibility, contract addresses/audits, precise liquidation formulas, real historical datasets, and task-based usability sessions with professional farm managers remain necessary.
