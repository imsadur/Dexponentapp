# Dexponent prototype

Professional strategists create, configure, review, simulate, and prepare Index, Spot, and Perpetual farms. This first milestone is a local, functional product prototype, not a live financial service.

## Journey

Landing → demo workspace or browser wallet connection → overview → create farm → strategy → template → configure → review → hypothetical simulation → deployment preview → saved READY farm.

## Scope

App shell, overview, farm list and detail, drafts, template catalog and detail, strategy catalog, analytics, settings, and six-stage creation. The template registry drives the configuration controls, validation, defaults, network choices, and live flow. Drafts persist in browser localStorage.

All seeded farms and performance are demo fixtures. Login enters a local demo session; it does not create an authenticated server account. Wallet connection requests public accounts only. The deployment adapter cannot send transactions. Team management and contract operations require backend integration.

## Acceptance

Three strategy families complete the journey. Invalid fields block review. Index weights must total 100. Changes invalidate simulation acceptance. Reload resumes drafts. New farms remain READY after preview. Search, filters, theme, and local profile persist or respond as labeled. Mobile layout works at 390px.
